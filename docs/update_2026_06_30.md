# 图像清理工具更新文档 - 2026-06-30

## 新增功能

### 后台任务中心

* 新增前端 `TaskCenter` 组件，用于展示最近的后端异步任务。
* 底部操作栏新增“任务”入口，任务存在时可打开弹窗查看任务名称、状态、进度、消息和短任务 ID。
* 任务中心支持取消当前活跃任务，并可一键清除已完成、失败或取消的历史记录。

### 结构化任务进度

* 前端 API 轮询新增 `onTaskProgress` 回调，除了原有状态文本外，也会把 `status`、`progress`、`message`、`state` 等结构化字段传给任务中心。
* 单图修复、AI 透明背景、AI 清晰增强、AI 切图、提示词重绘以及 AI 批量透明/清晰任务都会登记任务标签。
* 批量 AI 任务会带上文件名，例如 `批量清晰：demo.png`，便于区分多个同时排队的任务。

## 修复与优化

* 将任务活跃状态从单纯字符串数组升级为任务记录列表，活跃任务 ID 由记录状态派生，避免 UI 只能显示“有几个任务”却看不到具体进度。
* 新增纯工具函数管理任务记录创建、进度合并和活跃判断，降低 React hook 中的状态分支复杂度。
* 任务轮询超时时会写入失败状态，避免任务中心里长期停留在处理中。
* 修复前端 Docker 构建错误：将 `frontend/Dockerfile` 中已失效且不存在的 Nginx 基础镜像 `nginx:1.29-alpine` 替换为官方推荐的稳定版 `nginx:stable-alpine`，解决 BuildKit 因拉取不存在的镜像/镜像源在代理下返回 404 HTML 页面而报 `failed size validation` / `failed precondition` 错误的问题。
